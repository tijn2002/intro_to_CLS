Code implementation for all experiments/graphs/figures for the first assignment for Into to CLS.

File structure is as follows:

There are 3 assignment files, each corresponding to its problem. Inside the files, the subproblems are indicated with strings marking them X.Y, e.g. 2.1.
All files make use of some general functions defined in sir.py. Yes, there definitely should be some refactoring in that file, but I tried to keep things 
clear by naming all different integration functions very explicitly with a comment above it about what it does. 

PS: I thought it was okay to just hand in .py files, as during the lectures it was said that you could use any language that you were comfortable with. I therefore
do not have .ipynb version, but it should still be easy enough to rerun the tests!
